# Instaladores — macOS

Baixe na pagina de [Releases](https://github.com/lucas-reales/actus-releases/releases/latest).

| Arquivo | O que e |
|---|---|
| `Actus_x.y.z_aarch64.dmg` | Imagem de disco para Macs **Apple Silicon** (M1/M2/M3...) |

Abra o `.dmg` e arraste o **Actus** para a pasta Aplicativos.

> Enquanto o app nao for assinado/notarizado, o **Gatekeeper** pode bloquear na primeira abertura ("nao pode ser aberto porque a Apple nao pode verifica-lo"). Para abrir: **clique com o botao direito no app -> Abrir -> Abrir**. Apenas na primeira vez.
