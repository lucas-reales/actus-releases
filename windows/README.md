# Instaladores — Windows

Baixe na pagina de [Releases](https://github.com/lucas-reales/actus-releases/releases/latest).

| Arquivo | O que e | Quando usar |
|---|---|---|
| `Actus_x.y.z_x64-setup.exe` | Instalador NSIS (assistente) | **Recomendado** — instalacao simples, por usuario, com auto-update |
| `Actus_x.y.z_x64_en-US.msi` | Pacote MSI | Instalacao corporativa/silenciosa (GPO, scripts de TI) |

Ambos instalam o mesmo app (64-bit). Na duvida, use o `.exe`.

> Enquanto o app nao for assinado, o Windows pode mostrar um aviso do **SmartScreen** ("editor desconhecido") na primeira execucao. Clique em **Mais informacoes -> Executar assim mesmo**.
